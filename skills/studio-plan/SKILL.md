# studio-plan

Output `plans/<brand>-<week>.md` as a table: day, format (reel / carousel / story / photo), idea, hook formula id, asset needed, status.
- 3-4 posts per week is enough; consistency beats volume.
- Mix: one product/service post, one proof-or-answer post, one behind-the-scenes, one local-pride post.
- Reuse finished videos from `videos/` as reels; propose carousels from the same idea.
- Add 5 accounts to engage with, local to the brand's area, found by the user or via `studio-research` (public sources only).
- Do not schedule anything; scheduling happens only in `studio-publish` after approval.
